ChatGPT 對話備份

裝好之後，每則 ChatGPT 對話的右下角都會出現一顆「存對話」的按鈕，按一下就把整串對話存成檔案。裝一次就好，不用每次操作。

  1. 安裝 Stay

    Stay 是 Safari 的擴充功能管理器，負責讓下面那支腳本在 ChatGPT 網頁上跑起來。免費版就夠用。

    前往 App Store

  2. 去設定裡把它打開

    這步最多人漏掉——裝完 App 還要自己允許它讀 ChatGPT 的頁面，否則腳本不會動。

    設定 → App → Safari → 擴充功能 → Stay → 開啟

    同一頁裡把 chatgpt.com 的權限設成「允許」。

  3. 安裝腳本

    用 Safari 打開下面這個連結，會看到一頁程式碼，右下角有一顆 Install，按下去就裝好了。

    安裝對話備份腳本

  4. 回 ChatGPT 用用看

    打開任何一則對話，右下角會出現兩顆按鈕：

    存對話：按下去就開始，存好會顯示「已存 47 則 ✓」。
    存成 TXT：點一下換成 MD，再點換回來，選了會記住。

  1. 先換一個瀏覽器

    手機版 Chrome 裝不了擴充功能，所以這件事得換瀏覽器做。推薦 Firefox——它的附加元件裡就有竄改猴，不必另外找。

    下載 Firefox

    已經在用 Kiwi Browser 的人不用換，它也裝得了。

  2. 裝竄改猴（Tampermonkey）

    在 Firefox 裡：右下角選單 → 擴充套件，找到 Tampermonkey 按加入。它就是幫你跑腳本的那個管理器。

    開啟竄改猴的附加元件頁

    Kiwi Browser 的人改從 Chrome 線上應用程式商店搜「Tampermonkey」安裝。

  3. 安裝腳本

    用剛剛那個瀏覽器打開下面的連結（不要用 Chrome 開，Chrome 沒有竄改猴），竄改猴會跳出安裝畫面，按安裝就好。

    安裝對話備份腳本

  4. 回 ChatGPT 用用看

    在同一個瀏覽器裡打開 chatgpt.com，開任何一則對話，右下角會出現兩顆按鈕——上面那顆選檔案格式（TXT／MD），下面那顆「存對話」才是存檔。存好會顯示「已存 47 則 ✓」。

為什麼要裝一個管理器，不能直接用？因為腳本要跟著 ChatGPT 的網頁一起跑，而瀏覽器不會平白讓外面的程式進到網頁裡——Stay 和竄改猴就是負責把它接進去的人。它們是同一種東西，只是 iPhone 和 Android 各用各的。

它會拿到什麼？只有你自己那則對話的內容，而且整個過程都在你的手機上，沒有任何東西被送到別的地方。

不想用了怎麼辦？不必刪除——打開 Stay 或竄改猴，在腳本清單裡把它的開關關掉就好，按鈕就不會再出現。想用的時候再打開，不用重裝。

遇到狀況

右下角沒有按鈕

iPhone：先確認第 2 步做了——設定 → App → Safari → 擴充功能 → Stay 要是開啟，而且 chatgpt.com 的權限是「允許」。
Android：確認你是用裝了竄改猴的那個瀏覽器開 ChatGPT，不是 Chrome。
都對的話重新整理一次頁面，按鈕大約一秒內會出現。

存下來的檔案打不開

把格式切成 TXT（按鈕上方那顆小標籤），TXT 在手機上任何 App 都打得開。內容本身是 Markdown 寫法，貼進筆記軟體會自動排版。

檔案裡寫著「可能不完整」

那代表腳本沒能走官方那條路，改從畫面上抓——而 ChatGPT 只把你看得到的那幾則放在頁面裡，所以會缺。通常是登入狀態過期了，重新登入再存一次就會拿到完整的。

怎麼知道自己裝的是哪一版

打開存下來的檔案，最上面有一行「腳本: userscript v?.?.?」。回報問題時把那行一起附上，會省很多來回。
